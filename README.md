# Heidelberger SC Live Score

Live match tracking, automatic reporting, and season statistics for HSC.

## Overview

HSC Live Score is a purpose-built application for recording football match
events in real time from the sideline, generating match reports automatically,
and building season-long team and player statistics — without requiring
anyone to fill out a form or write a report after the game.

A designated team operator records events (goals, cards, substitutions,
saves, and more) with a small number of taps during the match. The system
turns that data into a live public score ticker, an automatically generated
match report, and ongoing team/player analytics.

This is a private project built for Heidelberger Sport-Club. It is not an open-source or
publicly licensed template, and it is not intended for use by other clubs
